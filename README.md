Это небольшой сайт для подготовки к заданию №14 ЕГЭ по русскому, а именно учить наречия и производные предлоги

### Как исправить ошибку в задании или добавить свои?

Задания описываются строками вида:

```js
C("before ", "task", " after", "answer", "type", "ta"),
```

В данном примере задание выглядит: `before (ta)sk after`.

- `before` — контекст до слова, включает пробел в конце
- `after` — контекст после слова, включает пробел в начале
- `task` — само слово в правильном написании
- `answer` — `"слитно"`, `"раздельно"` или `"дефис"`
- `type` — обычно оставьте `"memorize"`
- `ta` — часть слова, которая показывается в скобках

#### Как применить изменения?

Есть два способа:

1. Отправить pull request.
2. Скачать `index.html` и изменить его у себя
